作業はパソコンが進めておきます。あなたはスマホで確認するだけ。

dotz は自分のパソコンで動き続けるパーソナルアシスタントです。新着メールを読んで返信の下書きを用意し、あなたが送信を押すまで待ちます。

curl -fsSL https://raw.githubusercontent.com/ddotz/dotz/main/install.sh | sh
macOS · Linux · Windows（WSL 2）

まずデモで触ってみる

01

メールだけではありません。

  • スマホから話しかける

    席を外していても、いつものメッセンジャーで今日の予定やメールのことを聞けます。

    Web アプリ、Discord、Telegram、JANDI で会話でき、Slack では通知と返事を受け取れます。

  • 値下がりを逃さない

    見ておきたい商品を決めておけば、値段が下がったときにスマホへ知らせます。

    メール、カレンダー、YouTube・Instagram、Web サイトのコメントも見ています。

02

席に戻れば、すべてがひとつのアプリに。

会話、プロジェクト、見守っているものが、ひとつの Web アプリにまとまっています。プロジェクトごとにセッションが分かれていて、再起動や回線の切断で止まった作業は自動で再開します。

デモを開く

実際のアプリが、サンプルデータを使ってブラウザの中で動いています。画面は今のところ韓国語です。

03

自分のパソコンの中で動き、送る前に確認します。

承認しないと外に出ない
メール、返信、投稿はチャットで承認するまで送られません。
自分のパソコンで動く
パソコンにあるログイン情報やファイルをそのまま使い、秘密情報は ~/.dotz/secrets に保存します。
過去の会話を探せる
「先週のあれ」のような聞き方で大丈夫です。インデックス作成と検索はこのパソコンの中だけで行います。
オープンソース
MIT ライセンスです。コードはすべて GitHub にあります。
04

インストールはコマンド一行。

curl -fsSL https://raw.githubusercontent.com/ddotz/dotz/main/install.sh | sh
macOS · Linux · Windows（WSL 2）
Windows でインストールする
  1. 管理者として開いた PowerShell で wsl --install を実行します。
  2. 再起動後、Ubuntu のウィンドウに上のコマンドを貼り付けます。
  3. dotz は WSL の中で動き、そこから Windows を操作します。手順（韓国語）

セットアップ画面は英語と韓国語で、アシスタントは設定した言語で返事をします。

  1. macOS か Linux のターミナルにコマンドを貼り付けます。
  2. ブラウザが開くので、アシスタントの名前、話し方、つなぐサービスを選び、モデルのアカウントにログインします。
  3. 終わったら、ターミナルで dotz と打つと Web アプリが開きます。アップデートは自動で届きます。
