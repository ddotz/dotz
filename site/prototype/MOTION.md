# 모션 목록: 시제품에 실제로 구현된 움직임

`proto.css`와 `proto.js`에 있는 것만 적었어요. 숫자는 코드 그대로예요.

- **토큰**: `--m-fast` 150ms, `--m-base` 220ms, `--m-slow` 300ms, `--m-ease` = `cubic-bezier(.2, .7, .2, 1)`. JS 헬퍼도 같은 곡선(`EASE`)을 써요.
- **원칙**: JS 헬퍼는 `transform`과 `opacity`만 움직여요(Web Animations API). CSS 전환은 `transform`, `opacity`, `background-color`, `width`예요.
- **끄면**: 아래 표의 "끄면"은 모션을 끈 상태(툴바 "끄기" 또는 시스템 `prefers-reduced-motion`)에서 어떻게 되는지예요. 끈 상태에서는 CSS의 모든 `transition`과 `animation`이 `none`이 되고, JS 헬퍼는 애니메이션 없이 바로 최종 상태를 만들어요.

## 비교하는 법

1. **툴바 모션 켜기/끄기**: 화면 맨 위 툴바의 "모션 [켜기] [끄기]". 고른 값은 `localStorage`의 `dz-proto-motion`(`on` 또는 `off`, 기본 `on`)에 저장돼요. 켜고 끈 뒤 같은 동작을 다시 해 보세요. 끄면 `<html data-motion="off">`가 되어 모든 전환이 사라져요.
2. **시스템 설정**: 운영체제의 "동작 줄이기"(`prefers-reduced-motion: reduce`)가 켜져 있으면 저장된 값과 상관없이 모션이 꺼져요. 툴바도 "끄기"로 보여요. 저장된 값은 그대로예요. 설정을 풀면 원래대로 돌아와요.
3. **테마 따로**: 테마(라이트/다크)는 `dz-proto-theme`이고 모션과 독립이에요.
4. **같은 동작을 켜고 끄며 보세요**: 새로고침 없이 툴바만 바꿔서 같은 동작을 두 번 하면 차이가 가장 잘 보여요. 화면에 처음 들어올 때는 모션이 없으니(첫 그리기 뒤부터 켜져요) 다른 화면으로 갔다가 돌아오세요.
