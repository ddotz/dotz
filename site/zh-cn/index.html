事情交给你的电脑，你在手机上确认就行。

dotz 是在你自己的电脑上一直运行的个人助理。它读新邮件、写好回复草稿，然后等你点发送。

curl -fsSL https://raw.githubusercontent.com/ddotz/dotz/main/install.sh | sh
macOS · Linux · Windows（WSL 2）

先去演示里点点看

01

不只是邮件。

  • 在手机上问一句

    不在电脑前，也能用常用的聊天软件问今天的日程或邮件。

    可以通过网页应用、Discord、Telegram 或 JANDI 对话，Slack 用来接收通知和回复。

  • 降价不错过

    选好要关注的商品，价格一降，手机上就会收到通知。

    邮件、日历、YouTube、Instagram 和网站评论，它也一并盯着。

02

回到电脑前，一切都在一个应用里。

对话、项目和它盯着的东西，都在同一个网页应用里。每个项目有自己的会话，因重启或断网中断的工作会自动接着做完。

打开演示

这就是真实的应用，用示例数据在你的浏览器里运行。界面目前是韩文。

03

只在你的电脑上运行，发出去之前先问你。

不经你同意，什么都不发
邮件、回复和帖子都会留在聊天里，等你批准。
在你的电脑上运行
直接使用这台电脑上已有的登录状态和文件，密钥保存在 ~/.dotz/secrets。
能找回以前的对话
像“上周那个”这样随口一问也行。建索引和搜索都只在这台电脑上进行。
代码开源
采用 MIT 许可证，全部代码都在 GitHub 上。
04

一行命令就能安装。

curl -fsSL https://raw.githubusercontent.com/ddotz/dotz/main/install.sh | sh
macOS · Linux · Windows（WSL 2）
在 Windows 上安装
  1. 以管理员身份打开 PowerShell，运行 wsl --install。
  2. 重启后，把上面的命令粘贴到 Ubuntu 窗口里。
  3. dotz 在 WSL 里运行，并从那里操作 Windows。安装说明（韩文）

设置页面有英文和韩文，助理会用你设定的语言回复。

  1. 把这行命令粘贴到 macOS 或 Linux 的终端里。
  2. 浏览器会打开设置页面：选好助理的名字、说话方式和要连接的服务，再登录模型账号。
  3. 完成后，在终端输入 dotz 就能打开网页应用。更新会自动获取。
