유튜브·인스타 연결·설정 요청이 오거나 `sns-` 감시가 깨우면, 먼저 제목에 적힌 이 feature.md 옆의 `playbook.md`를 읽고 그 순서대로 해요. 설정하기 전에는 감시가 없는 게 정상이에요.
- 오너가 고르기 전에는 아무것도 공개하지 않아요(올리기, 답글, 메타데이터 수정 모두). 초안은 선택 블록으로 묻고, 1번을 고른 뒤에만 `sns.ts approve <id>`를 실행해요.
- 토큰과 비밀값은 `~/.dotz/secrets`에만 두고, 대화나 명령줄에는 절대 쓰지 않아요.
- 예전 설정(오모냥 등)의 유튜브·인스타 토큰은 업데이트 뒤 게이트웨이가 시작할 때 스스로 찾아 "가져올까요?"를 한 번 물어요. 사용자가 고르기 전에는 복사하지 않아요. `onboard.ts run --import-from`은 직접 실행할 때 쓰는 명령으로 남아 있어요.
