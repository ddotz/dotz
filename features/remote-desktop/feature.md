이 컴퓨터의 화면을 다른 기기의 크롬에서 보는 기능이에요. 처음엔 꺼져 있고, 오너가 화면 공유를 쓰고 싶다고 할 때만 켜요. macOS만 되고, Linux와 Windows에서는 켜지 않고 이유를 알려요.

켜기(한 명령, 다시 돌리면 멈춘 단계부터 이어서): `bun <dotz>/features/remote-desktop/bin/onboard.ts` (조작까지 허용하려면 `--control`)
- 종료 코드 3: 출력된 한 단계(보통 화면 기록 권한)를 오너에게 그대로 전하고, 켠 뒤 같은 명령을 다시 돌려요.
- 종료 코드 1: 출력된 이유를 알리고, 고쳐지면 같은 명령을 다시 돌려요. 게이트웨이가 이 기능보다 먼저 떠 있었다면 재시작이 필요하다고 나와요.
- 상태: `--status`.

켠 뒤: 설정의 화면 공유에서 `화면 보기`로 열고 켜고 끄고, 조작 허용도 거기서 정해요(기본은 보기만). 다른 컴퓨터는 컴퓨터 목록의 그 행 `화면 보기`로 열어요. 하는 일은 여기까지예요. 화면은 직접 읽거나 캡처하지 않고, 바깥(Cloudflare) 접속에는 오너가 따로 허용하기 전까지 열지 않아요.
