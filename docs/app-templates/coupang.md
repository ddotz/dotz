이 기기에 쿠팡 연결을 준비해 주세요.
- 자주 하는 일: 주문·배송 조회, 취소·반품 상태 확인, 상품 검색과 가격 비교, 골드박스 특가 확인. 그다음 장바구니 담기, 주문, 취소·반품 신청.
- 연결 방법: 1) coupang-product-search 스킬: 상품 검색, 로켓배송 필터, 가격대 검색, 베스트·골드박스는 돼요. 주문·배송 조회는 안 돼요(제 주문용 공식 API는 없어요). 판매자 배송 송장이 CJ대한통운·우체국이면 delivery-tracking 스킬로 볼 수 있어요. 2) 내 Aside 브라우저 로그인: 로그인 https://login.coupang.com/login/login.pang, 로그인 확인 https://mc.coupang.com/ssr/desktop/order/list, expect `주문목록`
- 내 정보: {{쿠팡 아이디(이메일·휴대폰)와 비밀번호(브라우저에 저장된 게 없을 때만)}}
- 막히는 곳: 일반 터미널 요청은 봇 차단(403)으로 막혀요. 새 기기 로그인 때 문자 인증, 쿠페이 결제 인증. 제 손이 필요한 단계: 인증번호 입력, 결제 비밀번호 입력.
- 바깥에 영향이 있는 동작(주문, 결제, 취소·반품 신청, 리뷰, 판매자 문의)은 보내기 확인 카드로 제 확인을 받은 뒤에만 해요. 결제는 제가 정확한 금액을 확인했을 때만 해요.
- 감시 제안: 주문 배송 상태가 바뀌면 알림 (30분마다), 제가 원할 때만 켜요.
- 확인 상태(2026-11-08): 브라우저에서 첫 화면이 열리고 주문목록 링크는 위 주소예요. 로그아웃 상태에서 주문목록을 열면 로그인 페이지로 가요(rtnUrl 포함). 터미널 요청은 403. / 확인 못 함: 로그인 뒤 주문목록 화면 문구.
