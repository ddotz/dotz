이 기기에 야놀자(NOL) 연결을 준비해 주세요.
- 자주 하는 일: 숙소·레저 예약 내역 확인, 체크인 날짜 확인, 쿠폰과 포인트 확인, 그다음 예약과 취소
- 연결 방법: 1) 소비자용 공식 API나 기존 스킬은 없어요. 야놀자 웹은 NOL(nol.yanolja.com)로 바뀌었어요. 2) 내 Aside 브라우저 로그인: 로그인 https://nol.yanolja.com/login (accounts.yanolja.com 로그인으로 넘어가요), 로그인 확인 https://nol.yanolja.com/member/mypage, expect `로그아웃|내 정보 관리`
- 내 정보: {{야놀자 아이디(이메일)와 비밀번호(브라우저에 저장된 게 없을 때만)}}
- 막히는 곳: 카카오·네이버 등 간편 로그인만 쓰는 계정, 휴대폰 본인인증, 일부 기능은 앱 전용이에요. 제 손이 필요한 단계: 간편 로그인 승인, 본인인증, 결제
- 바깥에 영향이 있는 동작(예약, 결제, 예약 취소, 리뷰)은 보내기 확인 카드로 제 확인을 받은 뒤에만 해요. 결제는 제가 정확한 금액을 확인했을 때만 해요.
- 감시 제안: 예약한 숙소의 체크인 전날 알림 (하루 1번), 제가 원할 때만 켜요.
- 확인 상태(2026-11-08): yanolja.com이 nol.yanolja.com으로 넘어감, 로그인 주소가 accounts.yanolja.com 로그인으로 넘어감, 마이페이지는 로그아웃 상태에서도 200으로 열림(화면에서 로그인 여부를 가려요) / 확인 못 함: 로그인 뒤 마이페이지 문구(expect), 예약 내역 페이지 주소
