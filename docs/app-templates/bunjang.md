이 기기에 번개장터 연결을 준비해 주세요.
- 자주 하는 일: 상품 검색과 시세 확인, 상품 상세 보기, 내 구매·판매 내역 확인, 찜 목록 확인. 그다음 찜하기, 판매자에게 채팅, 구매.
- 연결 방법: 1) bunjang-search 스킬(bunjang-cli): 검색·상세·여러 페이지 모으기는 로그인 없이 돼요. 찜·채팅은 CLI 로그인이 필요하고, 결제는 안 돼요. 공식 공개 API는 없어요. 2) 내 Aside 브라우저 로그인: 로그인 https://m.bunjang.co.kr/login, 로그인 확인 https://m.bunjang.co.kr/my/purchases, expect `구매내역|구매`
- 내 정보: {{번개장터 로그인 방식(카카오·네이버·애플·휴대폰 중)과 그 계정 정보(브라우저에 저장된 게 없을 때만)}}
- 막히는 곳: SNS 간편로그인 승인, 휴대폰 인증번호, CLI 로그인은 화면이 있는 터미널에서 직접 해야 해요. 제 손이 필요한 단계: 간편로그인 승인, 인증번호 입력, 번개페이 결제 인증.
- 바깥에 영향이 있는 동작(찜, 채팅 메시지, 구매, 결제, 후기)은 보내기 확인 카드로 제 확인을 받은 뒤에만 해요. 결제는 제가 정확한 금액을 확인했을 때만 해요.
- 감시 제안: 찾는 상품이 정한 가격 아래로 새로 올라오면 알림 (30분마다), 제가 원할 때만 켜요.
- 확인 상태(2026-11-08): 첫 화면과 로그인 페이지 200. 구매내역 주소도 200으로 열려요(앱 화면이라 로그인 유도는 화면 안에서 해요). / 확인 못 함: 로그인 뒤 구매내역 화면 문구.
