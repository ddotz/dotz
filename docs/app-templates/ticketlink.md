이 기기에 티켓링크 연결을 준비해 주세요.
- 자주 하는 일: 예매 내역 확인, 공연·스포츠 경기 일정과 오픈 일정 확인, 남은 좌석 확인, 그다음 예매와 취소
- 연결 방법: 1) 소비자용 공식 API나 기존 스킬은 없어요. 2) 내 Aside 브라우저 로그인(PAYCO 계정): 로그인 https://www.ticketlink.co.kr/auth/login (PAYCO 로그인 화면으로 넘어가요), 로그인 확인 https://www.ticketlink.co.kr/my/reserve/list, expect `예매번호|예매내역`
- 내 정보: {{PAYCO 아이디와 비밀번호(브라우저에 저장된 게 없을 때만)}}
- 막히는 곳: PAYCO 2단계 인증, 예매 때 보안문자(캡차), 대기열, 일부 경기의 본인인증. 캡차나 대기열은 넘기려 하지 않아요. 제 손이 필요한 단계: PAYCO 인증, 보안문자 입력, 결제
- 바깥에 영향이 있는 동작(예매, 결제, 예매 취소, 양도)은 보내기 확인 카드로 제 확인을 받은 뒤에만 해요. 결제는 제가 정확한 금액을 확인했을 때만 해요.
- 감시 제안: 관심 공연·경기의 예매 오픈 일정이 올라오면 알림 (하루 1번), 제가 원할 때만 켜요.
- 확인 상태(2026-11-08): 로그인 주소가 PAYCO 로그인(id.payco.com)으로 넘어감, 예매 내역 페이지는 로그아웃 상태에서 "로그인이 필요합니다" 뒤 로그인으로 보내는 스크립트가 있음 / 확인 못 함: 로그인 뒤 예매 내역 문구(expect)
