이 기기에 오늘의집 연결을 준비해 주세요.
- 자주 하는 일: 주문·배송 조회, 취소·반품 진행 상태, 포인트·쿠폰 확인, 스크랩한 상품 가격 확인. 그다음 주문, 취소·반품 신청.
- 연결 방법: 1) 일반 사용자용 공식 API는 없어요. 사이트가 봇 차단을 써서 curl 같은 직접 요청은 막혀요. 브라우저로만 봐요. 2) 내 Aside 브라우저 로그인: 로그인 https://ohou.se/users/sign_in, 로그인 확인 https://ohou.se/user_shopping_pages/order_list, expect `주문배송내역|로그아웃`
- 내 정보: {{오늘의집 이메일과 비밀번호(브라우저에 저장된 게 없을 때만)}}
- 막히는 곳: 간편 로그인(카카오·네이버·애플)은 그쪽 승인이 필요할 수 있어요. 봇 확인 화면이 나오면 넘기지 말고 저를 불러요. 결제 인증. 제 손이 필요한 단계: 간편 로그인 승인, 봇 확인 화면, 결제 인증.
- 바깥에 영향이 있는 동작(주문, 결제, 취소·반품 신청, 리뷰·댓글)은 보내기 확인 카드로 제 확인을 받은 뒤에만 해요. 결제는 제가 정확한 금액을 확인했을 때만 해요.
- 감시 제안: 주문한 상품의 배송 상태가 바뀌면 알림 (60분마다), 제가 원할 때만 켜요.
