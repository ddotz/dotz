이 기기에 CGV 연결을 준비해 주세요.
- 자주 하는 일: 예매 내역·모바일 티켓 확인, 상영 시간표와 남은 좌석 확인, 쿠폰·포인트 확인. 그다음 예매, 예매 취소.
- 연결 방법: 1) 공개 API나 기존 스킬은 없어요. 2) 내 Aside 브라우저 로그인: 로그인 https://cgv.co.kr/mem/login, 로그인 확인 https://cgv.co.kr/mcv/mobileTicketList, expect `모바일 ?티켓|예매`
- 내 정보: {{CGV 아이디와 비밀번호(브라우저에 저장된 게 없을 때만)}}
- 막히는 곳: 일반 터미널 요청은 봇 차단(403)으로 막혀요. 간편로그인을 쓰면 그쪽 승인이 필요해요. 결제 인증, 일부 기능은 앱 전용이에요. 제 손이 필요한 단계: 간편로그인 승인, 본인인증, 결제 인증.
- 바깥에 영향이 있는 동작(예매, 결제, 예매 취소, 리뷰)은 보내기 확인 카드로 제 확인을 받은 뒤에만 해요. 결제는 제가 정확한 금액을 확인했을 때만 해요.
- 감시 제안: 보고 싶은 영화의 원하는 시간대에 좌석이 열리면 알림 (30분마다), 제가 원할 때만 켜요.
- 확인 상태(2026-11-08): 브라우저에서 첫 화면이 열리고 로그인 버튼은 /mem/login 으로 가요. 모바일 티켓 화면은 로그아웃 상태에서 로그인 페이지로 보내요. 터미널 요청은 403. / 확인 못 함: 로그인 뒤 모바일 티켓 화면 문구, 로그인 방식별 인증 단계.
