# 카톡 연동

새 카카오톡 메시지가 오면 사용자 말투로 답장 초안을 만들어요. 사용자가 승인한 초안만 맥의 카카오톡 앱을 화면 자동화로 조작해서 보내요. 처음에는 꺼져 있고, 켜 달라고 하면 설정이 처음부터 끝까지 자동으로 이어져요.

## 지키는 것

- 카카오 메시지 API나 비공개 프로토콜은 쓰지 않아요. 보내는 길은 카카오톡 앱 UI 자동화([kmsg](https://github.com/channprj/kmsg)) 하나예요.
- 보내기는 초안마다 사용자가 대화에서 `보내기`를 고른 뒤에만 해요. 그사이 새 메시지가 왔거나 이름이 겹치는 대화방이 있으면 보내지 않아요.
- 카카오톡 DB는 읽기 전용으로만 열어요([kakaocli](https://github.com/silver-flight-group/kakaocli) 방식). 감시가 깨울 때는 대화방 id, 메시지 id, 시각만 넘기고, 본문은 초안을 쓸 때만 읽어요.
- 음소거해 둔 방(제외 목록), 광고·채널 방, 나와의 채팅, 내가 보낸 메시지는 초안 대상에서 빠져요.
- 카카오 아이디와 비밀번호는 macOS 키체인에 저장해요. 키체인을 쓸 수 없으면 `~/.dotz/secrets/kakao`(0600)에 저장해요. 메시지, 로그, 프롬프트에는 남기지 않아요.

## 켜기

"카톡 연결해줘"라고 말하면 돼요. 직접 하려면 `bun hub/kakao/cli.ts setup`을 실행해요. 설정은 백그라운드에서 이 순서로 진행되고, 진행 상황은 알림 메시지 하나를 계속 고쳐서 보여 줘요.

1. Homebrew로 `sqlcipher`와 `kmsg`를 설치해요.
2. 카카오톡 앱이 있는지 확인해요. 없으면 App Store 페이지를 뒤에서 열어요.
3. 사용자가 해야 할 일을 메시지 하나로 한 번에 물어요. 아이디·비밀번호 입력과 필요한 권한이 함께 들어가요.
4. 권한마다 시스템 설정의 정확한 화면을 뒤에서 열고, 켜질 때까지 기다려요.
5. 카카오톡을 숨긴 채로 띄우고 로그인해요. 휴대폰 기기 확인이 필요하면 그때 한 번만 물어요.
6. DB 위치를 찾고, 시험 삼아 읽어 보고, 1분마다 도는 감시와 홈 카드를 등록해요.

중간에 멈추면 멈춘 단계와 이유가 메시지에 남아요. 다시 "카톡 연결해줘"라고 하면 그 단계부터 이어서 해요. `setup --dry-run`을 쓰면 실제로 아무것도 바꾸지 않고 전체 흐름만 보여 줘요.

## 사용자가 허락해야 하는 것

- 전체 디스크 접근: 카카오톡 DB를 읽어요. 시스템 설정 > 개인정보 보호 및 보안에서 dotz 게이트웨이의 `bun`을 추가해요.
- 손쉬운 사용: 로그인 창과 보내기를 자동화해요. 같은 화면에서 같은 `bun`을 추가해요.
- 첫 로그인 때 휴대폰 카카오톡의 기기 확인

## 끄기

"카톡 연동 꺼 줘"라고 말하거나 `bun hub/kakao/cli.ts off`를 실행해요. 감시, 카드, 켜기 설정이 지워져요. `--forget`을 붙이면 저장한 계정 정보와 DB 키도 지워요.

## 설치마다 따로 남는 파일

- `~/.dotz/custom/kakao/config.json`: DB 위치, 제외할 대화방(`exclude_chats`), 묶음 대기 시간
- `~/.dotz/custom/kakao/watch.sh`: 감시 스크립트
- `~/.dotz/custom/cards/kakao/card.json`: 홈 카드
- `~/.dotz/features/kakao/feature.md`: 켜진 상태의 기능 설정
- `~/.dotz/kakao/`: 설정 진행 상태(`onboard.json`), 답장 초안(`drafts.json`)
