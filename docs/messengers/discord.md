# Discord 연결 (온보딩)

설정 → Discord 화면에서 **연결**을 누르면 dotz가 봇을 스스로 준비합니다. 봇 토큰, 서버 ID, 사용자 ID를 먼저 붙여 넣을 필요가 없습니다. 이미 있는 설정과 `~/.dotz/secrets/discord-bot-token`을 먼저 재사용합니다.

## 온보딩이 하는 일

1. `~/.dotz/secrets/discord-bot-token`, `config.json`의 `discord.app_id`, `discord.guild`, `discord.owner_id`를 확인합니다.
2. 토큰이 없으면 오너의 Aside 브라우저(백그라운드)에서 Discord 개발자 포털에 앱을 만들거나 같은 이름의 앱을 찾고, Bot 탭의 MESSAGE CONTENT를 켠 뒤 토큰을 발급받아 바로 `secrets/`에 저장합니다. 토큰은 화면, 로그, 보고에 나오지 않습니다.
3. 서버 ID가 없으면 오너가 로그인된 Discord 웹에서 서버 ID를 읽습니다. 사용자 ID는 봇 토큰으로 `GET /guilds/<서버>`를 읽어 채웁니다.
4. 봇이 서버에 없거나 관리자 권한이 없으면 관리자 권한(permissions=8) 초대 주소를 열어 승인합니다.
5. `GET /users/@me`와 서버 멤버 권한으로 연결을 확인합니다. 설정이 바뀐 경우에만 게이트웨이를 다시 시작합니다.

기존 설정이 이미 연결되어 있으면 1번과 5번만 하고 바로 끝납니다.

## 오너가 하는 일

자동으로 할 수 없는 것만 화면에 **한 단계**로 표시됩니다.

- Discord 로그인(QR 코드 스캔 또는 비밀번호)
- 2단계 인증(인증 앱 코드, SMS, 보안 키)
- 캡차
- 봇 초대 화면의 **승인**

화면의 안내를 끝내면 dotz가 이어서 진행합니다. 화면의 **했어요, 계속**을 누르거나, 안내가 사라질 때까지 기다리면 됩니다.

## 저장되는 것

| 무엇 | 어디 | 권한 |
| --- | --- | --- |
| 봇 토큰 | `~/.dotz/secrets/discord-bot-token` | 0600 |
| 서버 ID, 내 사용자 ID, 앱 ID, 토큰 파일 경로 | `~/.dotz/config.json`의 `discord` | 0600 |
| 온보딩 진행 상태(비밀 없음) | `~/.dotz/onboarding/discord.json` | 0600 |

## 복구와 연결 끊기

- 화면의 **직접 입력**을 열면 서버 ID, 내 사용자 ID, 봇 토큰을 직접 넣을 수 있습니다. 개발자 포털 화면이 바뀌어 자동화가 실패했을 때 쓰는 복구 경로입니다.
- **연결 확인**은 저장된 토큰으로 봇 이름과 관리자 권한을 확인합니다.
- **토큰 지우기**는 `secrets/discord-bot-token`을 지웁니다. 게이트웨이를 다시 시작하면 Discord 연결이 끊깁니다.
- 온보딩이 실패하면 화면에 이유 한 줄과 다음에 할 일 한 단계가 표시됩니다. **연결**을 다시 누르면 저장된 것부터 이어서 합니다.

## 한계

- 자동 준비는 오너가 로그인한 Aside 브라우저 세션을 씁니다. Aside가 멈춰 있으면 dotz가 백그라운드로 다시 띄웁니다. 브라우저 창을 앞으로 올리지 않고, 열었던 탭은 닫습니다.
- Discord 개발자 포털의 화면 구성이 바뀌면 자동 단계가 실패할 수 있습니다. 이때는 **직접 입력**으로 복구합니다.
- 봇은 한 서버에서만 동작합니다. 서버를 바꾸려면 **직접 입력**에서 서버 ID를 바꾸고 다시 연결합니다.
- 봇 초대에는 서버 관리자 권한이 필요합니다. dotz는 서버 관리자 권한을 요청합니다.
- 기존 `.dotz` 설치에서 이미 연결된 Discord는 그대로 동작합니다. 온보딩은 그 설정을 덮어쓰지 않습니다.
